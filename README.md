# Video Games REST API Server

A custom RESTful backend API server built with **Node.js** and **Express.js** supporting full CRUD operations (`GET`, `POST`, `PUT`, `DELETE`). This project manages a custom database of video game items as part of the **Build Your Own API Server Challenge**.

---

## 🚀 Tech Stack & Setup

* **Runtime:** Node.js
* **Framework:** Express.js
* **Data Store:** In-memory collection seeded from `seed.js`
* **Testing Tool:** Postman
